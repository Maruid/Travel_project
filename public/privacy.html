개인정보처리방침

시행일: 2026년 11월 1일

Trip Guide(이하 "서비스")는 여행 일정, 장소, 가계부, 할 일을 여러 사람이 함께 편집하는 개인 운영 웹 서비스입니다. 서비스는 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리합니다.

1. 수집하는 정보

구분항목수집 시점
Google 로그인 사용 시이메일 주소, 이름, 프로필 이미지 URL, Google 계정 식별자Google 로그인 또는 계정 연결 시
로그인 없이 사용 시임의로 생성된 익명 계정 식별자서비스 첫 이용 시
이용자가 입력한 정보여행에서 사용할 표시 이름, 여행 일정·장소·메모·지출 내역·할 일 등 직접 입력한 내용입력 시
자동 기록마지막 접속 시각여행 화면 이용 시

현재 위치(GPS)는 "내 위치" 기능을 누를 때 기기 안에서 거리 계산에만 사용하며 서버에 저장하지 않습니다. 이용자가 장소의 위치로 직접 저장한 좌표만 여행 데이터로 저장됩니다.

2. 이용 목적

  • 로그인 및 여러 기기에서 같은 이용자로 인식
  • 여행 데이터를 같은 여행에 참여한 멤버와 공유·동기화
  • 서비스 운영(이용 통계, 오류 확인, 남용 방지)

광고, 마케팅, 판매 목적으로 사용하지 않습니다.

3. 처리 위탁 및 외부 전송

수탁자내용
Supabase Inc.회원 인증, 데이터베이스 저장, 서버 기능 실행
Google LLCGoogle 로그인 인증. "AI로 정보 채우기"를 사용할 때 장소 이름·지역·좌표·지도 링크를 Gemini API 로 전송하여 장소 정보를 조회
GitHub Inc.웹사이트 파일 호스팅
OpenFreeMap / OpenStreetMap지도 표시 및 주소 검색 (검색어, 지도 영역이 해당 서비스로 전송됨)

위 서비스의 서버는 국외(미국 등)에 있을 수 있습니다.

4. 보관 및 파기

  • 여행 데이터는 여행이 삭제될 때까지 보관하며, 여행 owner 가 삭제하면 관련 데이터가 함께 삭제됩니다.
  • 계정 정보는 이용자의 삭제 요청 시 지체 없이 파기합니다.
  • 기기에 저장되는 오프라인 캐시는 로그아웃 시 삭제되며, 브라우저 데이터를 지워서도 삭제할 수 있습니다.

5. 이용자의 권리

이용자는 언제든지 자신의 정보 열람, 정정, 삭제를 요청할 수 있습니다. 여행 데이터는 서비스 화면에서 직접 수정·삭제할 수 있고, 계정 삭제 등은 아래 연락처로 요청하면 처리합니다.
